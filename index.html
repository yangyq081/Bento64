使用帮助

文本转换

在左侧粘贴原文，点击“编码为 Base64”。粘贴 Base64 后点击“解码 Base64”，可以还原原文。通常使用 UTF-8；旧系统的中文内容可尝试 GBK / GB2312。

文件与图片

拖入或选择文件进行编码。需要还原文件时，在输入框粘贴 Base64 或 Data URI，点击解码，再保存文件。单次支持最大 50 MB 的原文件。

格式选项

Base64URL 用 - 和 _ 替代 + 和 /。解码会自动识别这两种格式和缺失的末尾补位。Data URI 使用带补位的标准 Base64；选择 Base64URL 时会关闭 Data URI 前缀。十六进制模式直接处理字节，不经过字符集转换。GBK 模式兼容常见 GB2312 文本，遇到无法表示的字符会明确提示。

本地处理

转换不连接服务器，不保存历史记录。关闭窗口后，当前内容会清除。Base64 是可还原的编码方式，不能代替加密。
